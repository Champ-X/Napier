## 1. Node.js 账单工具：模块、编辑、数值和交付

> 在 expense-cli/ 创建只使用 Node.js 标准库的账单汇总 CLI。输入 CSV 字段 date、category、amount，支持引号字段、CRLF 和 UTF-8 BOM；按月份和分类汇总，金额用整数分计算。非法日期、缺失字段、超过两位小数须报告行号，不静默修正。拆分解析、金额、汇总和 CLI 模块，提供 calculateMonthlyTotals(rows) 接口。创建小样本和必要测试，实际运行后给出使用命令。验证 0.10+0.20=0.30、空输入、负金额退款和非法日期。

观察：文件是否可运行、错误输入是否被拒绝、金额是否准确、最终说明是否有真实执行依据。

## 2. Python JSONL：工具链和坏数据

> 在 log-summary/ 用 Python 标准库实现 JSONL 日志汇总器。记录有 timestamp、service、duration_ms；时间必须带时区，耗时必须非负且不能是布尔值。逐行读取，坏行报告行号和原因后继续。按 UTC 日期与服务统计 count、平均耗时和 nearest-rank P95，输出 JSON 与 CSV，支持中文。创建小样本并实际执行，覆盖跨时区、空文件、坏 JSON、非法耗时和单条记录；不要一次性读入整个文件。

观察：是否实际使用 Python，统计定义是否正确，坏行是否影响合法记录。不需要大数据压力测试。

## 3. 异步队列：复查已知的真实失败

> 在 async-queue/ 实现 runJobs(jobs,{concurrency=2,signal}={})。jobs 必须是函数数组，concurrency 是 1..32 的整数；signal 未提供或为 undefined 时允许，否则必须是真正的 AbortSignal，null 和仿造对象必须拒绝。所有参数在任何任务启动前校验。限制并发，结果按输入顺序返回；单任务失败不阻断其他任务。取消后停止启动等待任务，已启动任务返回真实结果，保留错误对象身份，不添加人为延迟。实际测试非法信号时启动次数为 0、预先取消、稀疏数组、运行中取消和同步抛错。

观察：null、带 aborted/addEventListener 的普通对象及预先 aborted 的仿造对象均须拒绝。不能只验证正常并发。
