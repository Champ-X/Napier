normalizeGraph(nodes) takes an array of {id,dependsOn}; IDs are nonempty strings, dependsOn is an array of distinct known IDs. Duplicate node IDs, duplicate dependencies, unknown references, self dependencies and cycles anywhere in the graph throw TypeError. Return a fresh Map from id to a sorted fresh dependency array, with IDs inserted in JS lexicographic order (not localeCompare). Do not mutate input.
planRollout(nodes,{selected=null,maxParallel=2}={}) returns arrays of deployment IDs. Validate the whole graph, including unselected nodes. maxParallel is integer 1..100. selected is null (all) or an array of unique known IDs, possibly empty. Include the transitive dependency closure of selected IDs, with no unrelated nodes. At each wave choose up to maxParallel lexicographically smallest remaining nodes whose dependencies completed in previous waves. Dependencies cannot be deployed in the same wave as their dependents. All returned arrays are fresh.
