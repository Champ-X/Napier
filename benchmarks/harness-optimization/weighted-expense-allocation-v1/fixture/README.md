parse_amount(text) converts a signed decimal amount string with exactly two fractional digits to integer minor units. Accept optional leading minus, no plus, whitespace, exponent or grouping separators. Leading zeros are allowed; -0.00 becomes 0. format_amount(minor) requires int (not bool) and returns a decimal string with exactly two fractional digits. No binary floating point.
allocate(total,weights,caps=None) requires integer total (not bool), a nonempty dict of nonempty string participant IDs to positive integer weights (bool invalid), and caps either None or a dict with exactly the same keys and nonnegative integer absolute limits. Return integer shares sorted by participant ID, whose sum is total; negative totals use the exact negation of the positive allocation. Allocation uses iterative largest remainder: among active participants, compute floor(remaining*weight/sumWeights), assign each floor up to remaining cap, then distribute at most one unit in descending fractional-remainder order (ties by ID), skipping full participants. Repeat with remaining amount and remaining capacities until fully assigned. Zero total validates inputs then returns zero for every participant. If total magnitude exceeds total capacity, raise ValueError. No input mutation.
