parseTagList(header) accepts a nonempty string up to 8192 characters. It returns '*' for a sole wildcard, otherwise an array of {weak,opaque}. Tags are quoted opaque ASCII bytes (allowed ! and # through ~), optionally prefixed with uppercase W/. Commas INSIDE quotes belong to the opaque tag. Separate tags with commas, allowing spaces/tabs outside tags. Reject CR/LF, malformed/missing quotes, invalid opaque characters, lowercase w/, dangling commas, mixed wildcard/tag lists and oversized headers with TypeError. Empty opaque tags are valid. Do not deduplicate tags.
evaluatePreconditions({method,exists,etag=null,ifMatch=null,ifNoneMatch=null}) returns null (proceed), 304 or 412. Validate all fields/headers before applying conditions. method is a nonempty ASCII letter token, compared case-insensitively; exists is bool. A supplied current etag must parse as exactly one tag, never '*', and cannot be supplied when exists is false. Existing resources may lack etag. If-Match uses strong comparison (both tags nonweak and opaque equal); '*' matches any existing resource. A failed If-Match returns 412 before evaluating If-None-Match semantics. If-None-Match uses WEAK comparison for every method; '*' matches any existing resource. A matching If-None-Match returns 304 for GET/HEAD and 412 for other methods. Missing conditions do not constrain the request. No mutation.
