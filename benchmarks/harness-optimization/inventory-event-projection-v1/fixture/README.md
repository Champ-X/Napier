normalize_events(events) accepts a list of dicts with exactly id,seq,sku,type,quantity. id and sku are nonempty strings; seq is a nonnegative int (not bool); quantity is a positive int (not bool); type is receive/reserve/release/ship. Repeated identical events with the same ID are deduplicated. A reused ID with different data or two distinct IDs sharing a sequence number raise ValueError. Return fresh dicts sorted by seq. Reject all malformed events with ValueError.
project_inventory(initial,events) accepts a dict mapping nonempty SKU strings to nonnegative integer available quantities (bool invalid). Normalize the whole event list before replay, then apply in sequence order: receive adds available; reserve transfers available to reserved; release transfers reserved to available; ship subtracts reserved permanently. Insufficient available/reserved quantities at any intermediate step raise ValueError; later events cannot mask that error. Unknown SKUs start at zero. Return a dict sorted by SKU with {available,reserved} values, retaining zero-stock SKUs. No caller input is mutated even when replay fails.
