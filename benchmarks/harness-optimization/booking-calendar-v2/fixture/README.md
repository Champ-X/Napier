parse_instant(text) accepts ISO-8601 datetime strings with an explicit timezone (Z accepted), returns a timezone-aware UTC datetime, and rejects invalid or naive datetimes with ValueError. normalize_bookings(bookings) validates an iterable list of dicts with nonempty string id/resource and start/end timestamps, strictly positive intervals, unique IDs. It returns fresh dicts with UTC datetime start/end, sorted by (resource,start,end,id), without mutating input.
reserve(bookings, request) validates all records and request, rejects a request ID already present with ValueError, and returns {accepted,conflicts,bookings}. Intervals are half-open: touching boundaries do not conflict. Only the same resource conflicts. conflicts is the sorted list of conflicting IDs. On rejection the returned bookings contain the original bookings; on success append the request. Returned booking entries keep their original input timestamp strings and are fresh shallow copies, preserving input order. No input mutations.
next_free(bookings,resource,earliest,duration_minutes) returns the first UTC ISO datetime ending in Z where a duration fits on the given resource. duration_minutes must be a positive integer (bool is invalid), resource a nonempty string. Validate every booking even on other resources. Merge overlapping occupancy conceptually and permit adjacency. Existing bookings ending at earliest are past. Never mutate inputs.
