# Settled event reconciliation
parse_events(text) reads CSV with header event_id,customer_id,kind,status,amount,occurred_at (header order arbitrary, exactly these names). IDs are nonempty strings after trimming. kind is charge/refund; status settled/pending. amount is unsigned decimal with exactly two digits after the decimal point, no whitespace/sign/exponent, and at most 12 integer digits. Timestamps must be ISO-8601 timezone-aware; Z is accepted. Invalid headers/rows/amounts/times throw ValueError, including missing/extra CSV columns. Blank physical lines may be ignored. CSV quoting must work.
Deduplicate by event_id before filtering: an exactly equivalent normalized event repeats once; conflicting reuse of the ID throws ValueError (including different customer/kind/status/amount/instant). Different timezone strings for the same instant are equivalent. parse_events returns a list; its private record shape is free as long as reconcile consumes it.
reconcile(events, start_date, end_date) selects settled events with UTC instant >= start_date midnight and < end_date midnight. Dates are ISO YYYY-MM-DD; start must be strictly before end, otherwise ValueError. Return a list sorted by customer_id with objects exactly {customer_id,charges,refunds,gross_total,refund_total,net_total}. Counts are event counts. Money fields are exact decimal strings with two decimals; net may be negative. Include customers with only refunds, exclude customers with no selected events. Do not mutate events. No binary floating-point rounding of money.
CLI: python -B src/main.py INPUT.csv START_DATE END_DATE prints the JSON list. Public tests: python -B -m unittest discover -s tests -v
