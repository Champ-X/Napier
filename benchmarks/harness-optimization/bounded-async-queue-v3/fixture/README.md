settleJob(job) asynchronously invokes a zero-argument function and returns {status:'fulfilled',value} or {status:'rejected',reason}, preserving the exact value or thrown/rejected reason identity. Catch both synchronous throws and rejected promises. Nonfunction input throws/rejects TypeError rather than returning a rejected result.
runJobs(jobs,{concurrency=2,signal}={}) validates jobs is an array of functions, concurrency is integer 1..32, and signal if supplied is an AbortSignal. Validate ALL inputs before invoking ANY job, even when already aborted. Return a Promise of fresh result records in input order. At most concurrency jobs may be active, started in input order. A job failure does not stop later jobs. On signal abort, stop scheduling jobs not yet started, mark them {status:'cancelled'}, and wait for every already-started job to settle with its ACTUAL outcome; do not label a started job cancelled or replace its result. Initially aborted signal starts no jobs. Empty input resolves []. No input mutation; never throw a job's own error from runJobs. Do not add timers or artificially delay dispatch.
