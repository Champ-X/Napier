parse_record(raw) accepts bytes containing exactly one UTF-8 JSON object. Reject nonbytes, malformed UTF-8, BOM, raw CR/LF, non-object top-level values, duplicate keys at ANY nesting level, NaN/Infinity constants with ValueError. JSON whitespace (space/tab) surrounding the object is allowed. Return fresh decoded values.
NdjsonDecoder(max_line_bytes=1024) requires a positive int (not bool). feed(chunk) accepts bytes, appends data and returns completed JSON objects in order, supporting arbitrary UTF-8 and line boundaries. LF ends a line; optional CR immediately before LF is framing. Ignore empty or space/tab-only lines. Limit each line to max_line_bytes BYTES excluding LF and optional framing CR, including whitespace. Apply the same limit to pending data without waiting for LF; a trailing CR may occupy one extra byte while awaiting LF. No other raw CR is valid. finish() parses a final unterminated nonblank line using the same rules; trailing CR at EOF is NOT framing and is invalid. Successful finish is idempotent (later finish returns []); feed after finish raises ValueError even for empty bytes. Any feed/finish error puts decoder into a permanent failed state, including wrong chunk type; every later call raises ValueError. If one chunk contains good lines followed by a bad one, feed raises without returning partial records. Previously returned data is never modified. No caller mutation or binary floating-point tricks for line length.
