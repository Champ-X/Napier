parseRetryAfter(value, nowMs) returns a nonnegative delay in milliseconds, or null for absent/invalid headers. Trim outer whitespace. Accept unsigned integer delta-seconds, or an exact canonical IMF-fixdate (Date.toUTCString form); past dates produce 0. Reject fractional/negative/nonfinite/overflow values and noncanonical/impossible dates. nowMs must be a nonnegative safe integer, otherwise TypeError.
retryDelay({method,status,attempt,retryAfter=null,nowMs,baseMs=100,maxMs=30000,maxRetries=3,jitter=1,idempotencyKey=null}) returns delay ms or null. Validate all options even for a nonretryable status. method is a nonempty ASCII letter token (case-insensitive); status is integer 100..599; attempt/maxRetries are nonnegative safe integers; baseMs/maxMs are positive safe integers; jitter is finite in [0,1]; key is null or a string. Retry only status 408,429,500,502,503,504, attempt < maxRetries, and method GET/HEAD/OPTIONS/PUT/DELETE, or POST with a nonblank idempotency key. Backoff is floor(min(maxMs,baseMs*2**attempt)*jitter), including huge attempt values without numeric overflow. Delay is max(backoff, valid Retry-After); if Retry-After exceeds maxMs, return null rather than retrying before the server permits. Invalid Retry-After is ignored. Never mutate options.
