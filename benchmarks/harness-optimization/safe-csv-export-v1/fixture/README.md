render_cell(value) returns text: None -> empty, bool -> lowercase true/false, int -> decimal, finite float -> str(value), str -> unchanged except formula mitigation. Other types or nonfinite float raise ValueError. For STRING cells only, if the first non-whitespace character is =,+,-,@, prefix one apostrophe BEFORE the original string (preserve whitespace). Negative numeric values are numbers, not formulas; do not prefix numeric cells. Already apostrophe-prefixed strings are unchanged.
export_rows(headers,rows) returns RFC-style CSV text with CRLF row endings including the final row ending, no BOM, and standard quoting/doubled quotes for commas, quotes and embedded newlines. headers is a nonempty list of distinct nonempty strings; row order and header order are preserved. rows is a list of dicts; unknown keys raise ValueError; missing columns are None. Apply render_cell to all header/value cells, including header formula mitigation. Validate without mutating headers or rows. Empty rows still yields a header line. All invalid inputs raise ValueError.
