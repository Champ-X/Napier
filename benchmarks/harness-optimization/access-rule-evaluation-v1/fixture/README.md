matchResource(pattern,resource) matches absolute slash-separated resource paths. Root / is valid. Other segments contain only ASCII letters/digits/underscore/dot/hyphen but cannot be '.' or '..'. Reject empty segments, trailing slash (except root), backslashes, query/fragment, percent-encoding and relative paths with TypeError. Patterns additionally allow * as an entire segment matching exactly one segment; ** is permitted only as the final whole segment and matches zero or more segments. Resource paths never contain wildcards.
explainAccess(rules,principal,action,resource) returns {allowed,matchedRuleIds,reason}. Rules are {id,effect,subjects,actions,resource}: unique nonempty IDs, effect allow/deny, nonempty distinct subjects from '*' or 'user:ID'/'group:ID' (ID uses path-segment characters and is not . or ..), nonempty distinct actions from read/write/delete/*, valid pattern. Principal is {id,groups} with valid ID and distinct valid group IDs. action is read/write/delete. Validate every rule and all inputs even if an earlier deny decides the result. A rule matches subject AND action AND resource. Deny overrides allow; default deny. matchedRuleIds contains all matching IDs in JS lexicographic order. reason is explicit_deny, allow, or no_match. No input mutation.
