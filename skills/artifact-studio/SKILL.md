# Artifact Studio

Treat the artifact as the product, not as an attachment to a chat response.

1. Identify audience, purpose, delivery format, and acceptance criteria.
2. Build a clear information hierarchy before adding detail.
3. Keep terminology consistent and remove unsupported filler.
4. Use tables or structured sections only when they improve retrieval.
5. Validate links, references, numbers, and file names.
6. Review the final artifact from the reader's perspective.

Prefer concise prose and concrete evidence. Preserve source material separately
from interpretation, and include provenance where claims depend on external
inputs.
